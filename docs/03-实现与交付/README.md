## 4. 任务拆解（按模块）

### 4.1 导入与解析
- 支持目录导入（递归、白名单）
- 文件解析：PDF/MD/TXT/DOCX
- 元数据抽取（标题、页码、来源）
- 错误处理与失败统计

### 4.2 切分与索引
- Chunk 规则（段落优先 + 长段再切）
- Chunk 元数据与 hash
- 向量写入（pgvector）
- FTS 写入（tsvector + GIN）

### 4.3 检索与融合
- 向量召回 + FTS 召回
- 线性加权融合与排序
- TopN 选择与去重

### 4.4 生成与引用
- Prompt 设计（答案 + 引用）
- LLM 调用（稳定一致）
- 引用合并与校验

### 4.5 API 与服务层
- REST + SSE 实现
- 任务状态查询
- 错误码与响应结构

### 4.6 简易 Web UI
- 查询输入与流式输出
- 引用展示（简洁版）
- 最小可用交互

### 4.7 运维与日志
- 基本日志（导入/查询/错误）
- 简单健康检查
