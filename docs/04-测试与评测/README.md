## 4. 评测与基准数据（双阶段）

### 4.1 数据来源
- **阶段一（小样本）**：人工构造 20–50 条问题，覆盖核心流程
- **阶段二（真实数据）**：引入业务文档与真实问题，形成回归基线

### 4.2 样本结构建议
- `query`
- `expected_answer`（要点）
- `expected_citations`（文档/页码/段落）
- `negative_citations`（可选）

### 4.3 指标口径
- 检索：Recall@K、nDCG
- 生成：答案准确率、引用正确率

### 4.4 评测流程
- 固定模型与参数
- 记录版本号、索引版本、评测时间
- 输出最小评测报告（表格 + 结论）
## 5. 评测样本模板

## 6. 评测脚本执行流程（建议）

1. 准备评测样本（CSV/JSON）
2. 对每条 query 执行检索与回答
3. 记录命中与引用情况
4. 统计 Recall@K、nDCG、引用正确率
5. 输出评测报告（表格 + 结论）
