# 架构与设计

## 1. 总体架构
- 模块：导入/解析 → 索引构建 → 检索 → 生成 → 引用组装
- 数据流：文档 → chunk → 索引 → query →候选→ rerank → answer + citations

## 2. 模块边界
- 文档导入与解析
- 索引层（向量 + 关键词）
- 检索与 rerank
- 生成与引用
- API 与 UI（如果有）

## 3. 数据与接口
- 输入：文件/目录、查询文本
- 输出：答案、引用、置信度
- 元数据：文档来源、页码/段落、时间

## 4. 关键决策记录（ADR）
- 使用 LangChain4j
- 向量库选型（待定）
- 混检策略（待定）

## 5. 风险
- 引用漂移（chunk 位置变化）
- 文档更新后的索引一致性
